# Fixing `splashkit.h` Include Errors in VS Code on macOS

When working on a SplashKit C++ project in VS Code on macOS, you may encounter an error such as:

```text
splashkit.h: No such file or directory
```

or:

```text
#include errors detected. Please update your includePath.
```

This can occur when VS Code cannot locate the SplashKit header files, even though SplashKit has been installed correctly.

---

## Solutions

### 1. Open the Project Folder in VS Code

Make sure you open the **entire project folder** rather than opening the `.cpp` file directly.

#### Steps

1. Open Terminal and navigate to your SplashKit project:

```bash
cd path/to/your/project
```

2. Open the project in VS Code:

```bash
code .
```

3. Open your `.cpp` file and check whether the error has disappeared.

Opening the entire project folder allows VS Code to correctly load the project's configuration and files.

---

### 2. Check the C/C++ Extension
<!-- Website / user friendly / dimention /   -->
Make sure the Microsoft **C/C++ extension** is installed in VS Code.

#### Steps

1. Open the **Extensions** panel in VS Code.
2. Search for **C/C++**.
3. Install the Microsoft C/C++ extension if it is not already installed.
4. Restart VS Code.

The extension provides IntelliSense and other C++ development features that help VS Code locate and understand header files.

---

### 3. Check the SplashKit Installation

First, test whether SplashKit can find the header file when compiling from Terminal.

Run:

```bash
skm clang++ *.cpp -o program
```

If the project compiles successfully, SplashKit is installed correctly and the issue is most likely related to VS Code's IntelliSense configuration.

If the same command reports that `splashkit.h` cannot be found, check whether SplashKit is installed:

```bash
ls ~/.splashkit
```

You can also search for the header file directly:

```bash
find ~/.splashkit -name "splashkit.h" 2>/dev/null
```

If the command finds `splashkit.h`, note its location. This path may be required when configuring VS Code's IntelliSense.

---

### 4. Reset VS Code IntelliSense

If your project compiles successfully using `skm clang++` but VS Code still displays the `splashkit.h` error, the problem is likely with VS Code's IntelliSense database.

#### Steps

1. Open the Command Palette using:

```text
Command + Shift + P
```

2. Search for:

```text
C/C++: Reset IntelliSense Database
```

3. Run the command.
4. Close and reopen VS Code.
5. Open the project again from Terminal:

```bash
cd path/to/your/project
code .
```

6. Open your `.cpp` file and check whether the error has disappeared.

---

## If the Error Still Appears

If:

```bash
skm clang++ *.cpp -o program
```

successfully compiles your program, but VS Code still displays:

```text
splashkit.h: No such file or directory
```

then SplashKit itself is most likely working correctly.

The remaining issue is usually **VS Code IntelliSense configuration**, specifically the paths used by the C/C++ extension to locate SplashKit's header files.

In this situation, check your VS Code C++ configuration, particularly the `.vscode/c_cpp_properties.json` file, and make sure the SplashKit header directory is included in `includePath`.

> **Important:** A red underline in VS Code does not necessarily mean that your SplashKit program will fail to compile. If `skm clang++` successfully builds the program, the error may only be an IntelliSense warning.
